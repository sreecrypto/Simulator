Your electronics workbench
Open Components to place a component family. Right-click or double-click a part to edit its value and connections. Shift-click selects groups; the context menu supports rotation, mirrors, copies and deletion.
Wiring: click Connect pins, then two pins to assign a shared net name. All matching node names connect electrically, including ground node 0. Lines show shared nets. Delete a connection by editing a pin's node name.
Analysis: R, C, L, voltage and current sources support DC, transient and AC. Transient uses zero energy initial conditions and backward Euler. AC treats every independent source value as its real phasor amplitude; one source is recommended for transfer measurements.
Digital: click INPUT components to toggle 0/1. Run creates a truth table; Tick advances clocks and D flip-flops.
Assistant: smart builders support arithmetic circuits, counters, shift registers, decoders, active filters, bridges and the original starter circuits. Local AI requires Ollama plus OLLAMA_MODEL in the server environment. Proposals replace the current circuit only when you click Apply. Undo restores the previous circuit.
Advanced semiconductor models require an installed ngspice engine. Resources imports self-contained SPICE models and data packs. Verilog + TB exports digital designs. Full LTspice library compatibility, PCB layout and mixed-signal co-simulation are not implemented. See README.md for setup and limits.

Function generator

    
    
    
    
    
    
  
Independent sources provide multiple channels. Amplitude is unloaded; source resistance changes voltage under load. Sweep is one-shot, burst ends at offset, and noise is deterministic. These are modeled controls, without a physical instrument's bandwidth or calibration.

  
Extensions & model resources
Import self-contained .model / .subckt text or JSON model packs. Control scripts, executable plugins and external include commands are rejected. Pin order follows the model definition. Source URLs are also available to the copilot for missing-model retrieval.
